# References

This project was inspired by the modular soft pneumatic actuator architecture reported in:

A. R. Elchrif, M. I. Awad, S. A. Maged, and A. Ramzy,  
“Modular soft pneumatic actuator mimics elephant trunk locomotion,”  
*Scientific Reports*, vol. 14, Art. no. 24169, 2024.  
DOI: 10.1038/s41598-024-74105-0

The reference paper is cited for design inspiration and modeling context only.  
Its PDF is not redistributed in this repository.
